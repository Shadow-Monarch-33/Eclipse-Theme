# Eclipse

Two atmospheric dark themes for VS Code: **Eclipse: Lunar**, the original eclipse theme, and **Eclipse: Solar**, a near-black theme built around the faint glow of a dying ember.

Eclipse was made for coding late at night, especially when your laptop is the main light in the room. Both themes keep the interface dark and restrained while giving syntax enough color to stay easy to read.

## Design

Both themes are built around the same idea: **keep the screen dark without making the code difficult to read.**

The UI uses subtle differences between surfaces instead of bright borders and heavy contrast.

**Eclipse: Lunar** leans into violet, midnight blue, copper, and gold.

**Eclipse: Solar** goes much darker, using warm browns and burnt-orange accents against an almost black background.

## Features

- Two themes in one extension: **Eclipse** and **Eclipse: Event Horizon**
- Full VS Code UI theming
- Rich syntax highlighting
- Dark, low-glare interface
- Subtle surface hierarchy
- Distinct syntax colors without excessive brightness
- Built with long coding sessions in mind

## Installation

### Open VSX

Search for **Eclipse** in your editor's Extensions panel and click **Install**.

You can also install it directly from the Open VSX Registry.

### Manual installation

To install from a `.vsix` file:

1. Open your editor
2. Open the Extensions panel
3. Click `...`
4. Select **Install from VSIX...**
5. Select the Eclipse `.vsix` file

### Choose a theme

After installing:

1. Open the Command Palette:
   - **macOS:** `⌘ + Shift + P`
   - **Windows/Linux:** `Ctrl + Shift + P`
2. Search for **Preferences: Color Theme**
3. Choose **Eclipse** or **Eclipse: Event Horizon**

And you're ready for the night.

## Recommended

Eclipse was made with dark and nighttime environments in mind.

For the intended experience:

- Use it in a dim or dark environment
- Keep your display brightness comfortable
- Pair it with whatever font and editor settings you prefer
