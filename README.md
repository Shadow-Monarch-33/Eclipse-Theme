# Eclipse

**Two atmospheric dark themes for VS Code: the classic violet shadow of **Eclipse** and the ember glow of **Eclipse: Event Horizon**.**

Designed for coding after dark, especially in an environment with little to no light. Dark, atmospheric, and built to stay comfortable when your laptop is the last light left in the room.

## THEMES

The original Eclipse theme — a deep violet, midnight interface. Refined for better consistency, contrast, and syntax differentiation while keeping its familiar nocturnal identity.

### Eclipse: Event Horizon

A brand-new theme that sits at the edge of a black hole — **almost complete darkness with a faint, burning orange accretion disk surrounding it**.

The interface is 90% darkness, 8% burnt orange, and 2% ember/gold. Orange is used strategically — as a glow emerging from darkness, never a flood.

## DESIGN

Both themes were explicitly designed to be easy on the eyes over long sessions. Editors stay dark while surrounding UI elements remain subtle and understated. Syntax colors are intentionally distinct — keywords, functions, types, variables, strings, and comments each get a clear, consistent role in the hierarchy — but kept controlled enough for hours of work.

**Eclipse** uses a rich violet foundation rather than pure black, with copper and gold accents. **Event Horizon** is nearly black with warm browns for hierarchy and burnt-orange embers for the few things that matter most.

## FEATURES

- Two themes in one extension: **Eclipse** and **Eclipse: Event Horizon**
- Fully themed VS Code interface (activity bar, tabs, panels, terminal, command palette, notifications, diff editor, and more)
- Rich, multi-color syntax highlighting
- Low-glare UI designed for dark environments
- Subtle surface hierarchy instead of loud outlines
- Designed for long coding sessions

## INSTALLATION

### Open VSX

Search for **Eclipse** in your editor's Extensions panel and click **Install**.

Or install it directly from the Open VSX Registry.

### Manual installation

If you're installing from a `.vsix` file:

1. Open your editor
2. Open the Extensions panel
3. Click `...`
4. Select **Install from VSIX...**
5. Choose the Eclipse `.vsix` file

### Activate a theme

After installation:

1. Open the Command Palette:
   - **macOS:** `⌘ + Shift + P`
   - **Windows/Linux:** `Ctrl + Shift + P`

2. Search for **Preferences: Color Theme**

3. Select **Eclipse** or **Eclipse: Event Horizon**

And you're ready for the night.

## RECOMMENDED

Eclipse is designed for use in low-light and nighttime environments.

For the intended experience:

- Use in a dim or dark environment
- Keep your display brightness at a comfortable level
- Pair with a font and editor settings you find comfortable for long sessions
